# Spine Cooling - Tissue Cooling Simulation

Python toolkit for simulating and verifying thermal dynamics in tissue cooling systems using heat transfer principles.

## Quick Start

1. **Setup:** 
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. **Run simulation or Experiment:** Example: `Models/SpringSemester_Body_and_Catheder/finalcombined.ipynb`

## Structure
- **Models/** — Simulation models
- **Experiments/** — Experiments conducteddurint the work on Cool Spine prototype (see Dropbox for destribtion)
